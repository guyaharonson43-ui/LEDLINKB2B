# אפיון: שכתוב סינון הדרייברים בקטלוג

**תאריך:** 2026-09-05
**היקף:** ציר סינון הדרייברים ב-`src/catalog` — 241 מוצרים בקטגוריית "דרייברים".

## הבעיה

הסינון הקיים (`DriverFilters.jsx` + `PS_*` ב-`filterConstants.js` + `App.jsx:201-224`) לא מכסה את הנתונים בפועל:

1. **123 מוצרי CC בלי ציר סינון יציאה.** `specs.voltage` מחזיק אצלם מיליאמפר (70–1350mA). הקוד מסתיר אותם אקטיבית: `if (s.outputMode === 'CC') return false`.
2. **צ'יפים שמחזירים אפס:** `IP67`, `IP68`, `Resistor` — 0 מוצרים כל אחד.
3. **ערכים אמיתיים בלי צ'יפ:** IP40 (20), IP00 (7), IP44 (3), IP66 (3) = 33 מוצרים לא נגישים. עמעום — IGBT (18), MOSFET (17), 1-10V (15), BLE (12), ZIGBEE (12), RF (10), DMX (7). אין "ללא עמעום" (145 מוצרים).
4. **באג נתונים — 27 מוצרים מוסתרים.** מתויגים `outputMode:'CC'` אך `voltage` שלהם `12V`/`24V`/`48V` (`PLP105N`, `NICE303`, `TRACK28`, `MININICE3`...). בפועל CV, ונעלמים מכל סינון מתח יציאה.
5. **הספק:** 41 מוצרים עם `power:""` נופלים בשקט מכל סינון. הסולמות בנויים ל-CV (12–336W); ל-CC הטווח 3–90W ו-59 מ-123 נדחסים לדלי אחד.
6. **גבולות חופפים:** `min`/`max` שניהם inclusive — 30W נכנס גם ל"עד 30W" וגם ל"30–60W".
7. **19 מוצרים שאינם דרייברים** (מתגי קיר, שלטים, חיישן PIR, גשרי DALI/DMX) מזהמים כל ציר.
8. **שתי שורות מתגים חופפות:** `smartType` (`הכל | מוצרים חכמים | קונברטורים`) חותכת את אותם מוצרים בציר אחר מהסינון בסיידבר.

## ארכיטקטורה

### `src/catalog/utils/driverMeta.js` (חדש)

`getDriverMeta(product)` מחזיר אובייקט מנורמל יחיד. אף קומפוננטה לא נוגעת יותר ב-`product.specs` הגולמי.

**כלל שיוך הקבוצה — נגזר מצורת ערך המתח, לא מ-`outputMode`:**

```
אין outputMode, או outputMode === 'DALI'  ->  ACC  (19)
voltage בתבנית /^\d+MA$/                   ->  CC   (96)
אחרת                                        ->  CV   (126)
```

מתקן את באג 27 המוצרים בלי לערוך את `products_data.js`, ומרפא את עצמו בייבוא הבא.
שלוש הקבוצות מחלקות את 241 המוצרים בדיוק — בלי חפיפה ובלי שאריות.

**נורמליזציות:** `100÷250V AC` / `110V` / `230V` -> `AC 100-240V` · `PWM-250-400HZ` -> `PWM` · `RF-24GHZ` -> `RF 2.4GHz` · `multiCurrent: /MULTICURRENT/i.test(name)`.

### `src/catalog/utils/driverFacets.js` (חדש)

בונה את רשימות הצירים מקבוצת המוצרים הנוכחית ומחשב מונה לכל ערך **מול כל שאר הצירים הפעילים, למעט הציר של עצמו**. סדר ותוויות ממפת curation; הרשימה עצמה תמיד מהנתונים.

| מתח יציאה (יחיד) | — | + | — | — |

### סולמות הספק — נפרדים לכל קבוצה

גבולות `min < v <= max` (סוגר את החפיפה).

- **CV:** עד 30W (30) · 30–60W (25) · 60–100W (38) · 100–200W (22) · 200W+ (8)
- **CC:** עד 10W (11) · 10–25W (35) · 25–45W (16) · 45W+ (13)

### ציר העמעום — חמש משפחות

```
ללא עמעום
אנלוגי     0-10V  1-10V  PWM
פאזה       TRIAC  IGBT  MOSFET
דיגיטלי    DALI  DMX  PUSH
אלחוטי     ZIGBEE  BLE  RF 2.4GHz
```

### מצב

```js
INIT_PS = { group:'הכל', voltage:'הכל', current:[], inputVoltage:'הכל',
            ip:[], dimming:[], power:'הכל' }
```

מחרוזת = בחירה יחידה, מערך = רב-בחירה (OR בתוך ציר, AND בין צירים).
החלפת קבוצה מאפסת את שאר הצירים.

## ידוע ולא מטופל

22 מ-96 מוצרי ה-CC הם MULTICURRENT — הנתונים שומרים ערך זרם אחד בלבד, למרות שהמוצר תומך בכמה. הם יופיעו בסינון לפי הערך היחיד שרשום. תג "זרם נבחר" מסמן זאת למשתמש. תיקון מלא דורש חילוץ מהדאטהשיטים — עבודה נפרדת.

## נמצא במהלך היישום

**שני מוצרי CV בלי מתח יציאה רשום** — `IDNDP010 DIN` ו-`IDNDP110 DIN` (`voltage: ""`).
בגרסה הראשונה של `valuesOf` הם החזירו מערך ריק ונשרו מציר מתח היציאה בשקט —
בדיוק סוג הבאג שהמסמך הזה בא לסגור. תוקן: כל ציר מחזיר `UNSPECIFIED` במקום
מערך ריק, ולכן `12V 22 + 24V 89 + 48V 13 + לא צוין 2 = 126`.

**בדיקת שלמות הצירים** — לכל קבוצה, סכום המונים בכל ציר חייב להיות בדיוק
מספר המוצרים בקבוצה. זו ההגנה המבנית מפני נשירה שקטה, והיא זו שתפסה את
IDNDP. חריג יחיד: ציר העמעום, שבו מוצר יכול לשאת כמה ערכים.

**`ProductModal`** הוצמד גם הוא ל-`getDriverMeta`. קודם הוא הציג את השדות
הגולמיים, כלומר "מתח: 350MA" על דרייבר זרם-קבוע ו"מצב יציאה: CC" על `CPL206`
שהוא CV — סתירה מול הכרטיס שכבר הראה 24V.

## אימות

29 בדיקות מול הנתונים האמיתיים + 12 בדיקות שלמות צירים — עוברות.
מכסות: חלוקת הקבוצות, 27 המוצרים המתויגים שגוי, OR רב-בחירה, AND בין צירים,
מונים faceted שאינם מסננים את הציר של עצמם, סדר וסינון הצ'יפים, וסולמות ההספק.
